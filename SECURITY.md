# Security

phos-org tools run on your desktop with your permissions, and some read
personal data, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue.** Report it privately, by email to
**security@phos.sh**, or through the affected repository's **Security** tab →
**Report a vulnerability**.

Include what an attacker could do, how to reproduce it, and the commit you
tested (`git rev-parse --short HEAD`). You will get an answer within a week,
and credit in the fix unless you would rather not.

A project may have its own `SECURITY.md` with more detail on what is in
scope; it takes precedence over this one.
