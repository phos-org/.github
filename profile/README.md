**phos** (φῶς) is Greek for *light*. We make small, carefully built tools for
the Linux desktop: things you look at all day, so they should be beautiful,
quick, and never in your way. **Light, not bloatware.**

### Projects

| | |
|---|---|
| **phos widgets** | Glass desktop widgets for Hyprland. Drag them anywhere, restyle each one, and get widgets for the apps you actually use. *Coming soon.* |
| **hypr-displays** | A display settings panel for Hyprland: arrange monitors, set modes and scaling, and get your old layout back if a change goes wrong. *Coming soon.* |
| **phos themes** | One theme for your whole desktop, switched in one step: Hyprland first, then KDE, XFCE and GNOME, with community themes to browse. *Coming soon.* |

### What we care about

- **Local first.** No accounts, no telemetry. What runs on your machine stays there.
- **Light on resources.** Tools that sit on your desktop all day should cost next to nothing.
- **Your setup, not ours.** Nothing assumes a particular distribution, terminal, theme or city: it is detected, and you can override it.
- **Documented.** Every project has a wiki written for someone seeing it for the first time.

### Taking part

Issues, ideas and pull requests are welcome in every project. Start with the
project's own `CONTRIBUTING.md`; the [shared conventions](https://github.com/phos-org/.github/blob/main/CONTRIBUTING.md)
apply everywhere.
