# phos-org/.github

What every phos-org repository shares:

- **`profile/`**: the organization's page on [github.com/phos-org](https://github.com/phos-org).
- **Community files** every repository inherits unless it has its own: the
  code of conduct, security policy, support guide, contributing
  conventions, issue forms and pull request template.
- **`workflow-templates/`**: workflows any repository can add in one click
  from **Actions > New workflow > By phos-org**:
  - **Auto-assign issues**: assigns new issues to the maintainers in the
    `ISSUE_ASSIGNEES` variable.
  - **CI**: scripts parse, and the project's npm and pytest suites pass.
